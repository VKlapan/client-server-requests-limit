### EXPRESS SERVER SIDE
## Installation
```bash
npm install
```

## Local Development

```bash
npm run start:dev
```

## Run tests
```bash
npm run test
```

## Environment Variables

- `PORT` - Server port (default: 3000)
- `REDIS_HOST` - Redis host (default: localhost)
- `REDIS_PORT` - Redis port (default: 6379)
- `NODE_ENV` - Environment (default: development)
